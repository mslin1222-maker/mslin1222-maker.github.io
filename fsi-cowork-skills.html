STEP 04 · SKILL 工作台

打開一個 Skill,模擬執行它

工作台是全螢幕的滑出式面板 (slide-over drawer):左邊是可自動播放的工作流程模擬器與產出預覽,右邊是 SKILL.md 預覽、原始碼、範例 Prompt 與法遵護欄。

工作台裡有什麼

  • ▶ 模擬執行:每個 Step 逐一亮起,附上 M365 活動紀錄(讀取 input/…、搜尋 Outlook…、產生 output/….docx)。
  • 產出預覽:輸出文件骨架會隨步驟完成逐段填滿,最後蓋上「待人工覆核」章。
  • SKILL.md:渲染預覽(含 YAML frontmatter)、原始碼、一鍵下載/複製。
  • 鍵盤:Esc 關閉、←→ 切換 Skill;網址 #skill/<slug> 可深連結。

STEP 06 · 治理與護欄

為什麼是 Skill,而不只是問一次 Chat?

Cowork Skill 把「怎麼做、用哪些資料、輸出長什麼樣、哪裡必須有人簽核」寫進 SKILL.md,每次執行都一致、可稽核。

面向Copilot Chat 單次問答Cowork Skill
執行方式單輪回答,靠使用者一步步追問多步驅動 (multi-step):Step 1→N 自動串接,含檢核點
資料來源貼上的文字或單一附件input/ 上傳 + SharePoint + Outlook + Teams 跨來源整合
可稽核性只有對話紀錄每步活動紀錄 + 輸出檔案存 output/,可追溯到原始科目/來源
輸出一致每次格式不同固定章節骨架/Excel 欄位,便於覆核與比對
Human-in-the-loop依使用者自律最後一步固定「交付草稿供人工覆核」;決策權留給主管/授審會/專責人員
去識別化依使用者自行處理SKILL.md 內建護欄:個資最小化、不儲存證件影像、模擬資料示範
交易/申報可能被誤用來直接產生對外文件明文不觸發交易、不送出申報、不寄出信件 — 只存草稿
法遵對應無每份 SKILL.md 有「法遵與護欄」章節,對應相關法規/自律規範原則

STEP 08 · 打包與部署

把 22 個 Skill 帶回去

三步完成:下載、放進 OneDrive 個人技能資料夾(或打包成 plugin)、上傳。

①

下載全部 SKILL.md (.zip)

瀏覽器內直接打包(無需外部程式庫),含 22 個 skills/<slug>/SKILL.md 與一份 README.md 索引。

②

放入 OneDrive「文件/Cowork」個人技能資料夾

解壓後把每個 <slug>/ 資料夾放進你的個人技能資料夾;或把多個 skill 打包成一個 plugin。

OneDrive/文件/Cowork/ ├─ regulatory-change-impact/ │ └─ SKILL.md ├─ credit-memo-5p/ │ └─ SKILL.md └─ … (共 22 個)
③

上傳並在 Cowork 中測試

上傳後用範例 Prompt 觸發,確認 Skill 命中與輸出章節;所有產出仍需人工覆核。

「請用 credit-memo-5p 技能, 讀取 input/模擬企業A_財報_3年.pdf, 產出 5P 授信報告初稿到 output/」
ℹ 這個 .zip 不含 manifest.json — manifest.json 請沿用你已驗證的 devPreview 版本。
